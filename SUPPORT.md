# Support

Use the narrowest channel that matches the request.

## Project Issues

Open a repository Issue for:

- reproducible downloader or data-processing defects;
- verified PeMS schema or catalog changes;
- feature proposals with a concrete research use case;
- documentation corrections.

Use the provided Bug Report or Feature Request form. Search existing Issues
before opening a new one.

## Caltrans PeMS support

Contact [Caltrans PeMS](https://pems.dot.ca.gov/) for account approval,
password recovery, source-data availability, and official data-definition
questions. This project cannot approve accounts or change PeMS publication
schedules.

## Research and model support

Use the
[`wcc961129/GE-GAN` issue tracker](https://github.com/wcc961129/GE-GAN/issues)
for GE-GAN implementation questions. See
[`wcc961129/transdim`](https://github.com/wcc961129/transdim) for other
open-data and matrix/tensor modeling resources.

## Security

Do not open a public Issue for credential disclosure, cookie leakage,
authentication bypass, or another vulnerability. Follow
[SECURITY.md](SECURITY.md) and use the repository's private vulnerability
reporting form.

## Information to include

Provide the operating system, Python version, project version or commit,
sanitized command, expected behavior, actual behavior, and the smallest
reproducible example. Never attach `.pems/storage-state.json`, credentials,
cookies, or complete downloaded source archives.
